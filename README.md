# Squirrel Witchery
REQUIRES [CLEANROOM MODLOADER](https://cleanroommc.com/) AND [RIFTLIBRARY](https://github.com/Rift-Modding-Group/RiftLibrary).

Squirrel Witchery is a Thaumcraft 6 addon themed around the VTuber Ayunda Risu, more specifically, her witch persona Ayunda. Play as Ayunda but as a thaumaturge, studying the thaumaturgical properties of Risunium…
